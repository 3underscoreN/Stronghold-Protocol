## 37. 0.3.4

### 人机让出队友的特化干员、少选鸭爵（#121，round54）

报告：「我玩潘格尼尼，AI 玩歌利亚大量抓我拉特兰」；AI 选鸭爵后自己守不住，金币怪还冲垮队友的防线。原规则（PR #407）只对
5–6 阶、且与存活队友**开局策略**盟约重叠的共享干员扣 18 分，低阶拉特兰不受影响；选策略时鸭爵也不会因为队友降低权重。

改动（`server/match/bot.js`，均为 [ASSUMED] 的人机取舍，不是官方规则）：

- `teammateBonds`：每名存活队友需要的盟约 = 开局策略的盟约 + 公开盟约栏上的主核心盟约（`mainCoreBond`），减去自己开局
  策略需要的盟约和本模式关闭的盟约。真人与人机一样；多名队友不叠加；淘汰的队友不再计入；单人为空。
- 买牌：干员的盟约落在其中时扣分，5–6 阶仍是 18，1–4 阶为 12。凑齐三合一（MERGE_HIT +30/+40）或缺阻挡／治疗
  （+10／+14）仍压过这项扣分。
- 选策略：机制会改变队友敌人的策略（鸭爵「神秘顾客」：第 5 回合起自己和队友遭遇的部分敌人换成鸭爵／高普尼克／流泪小子／
  圆仔）在有存活队友时只保留十分之一权重（`MATE_BURDEN` = 0.1，按描述识别）；单人照旧。

测量（`node tools/botbench.mjs --configs coop4:ABYSS,coop4:HARD,coop2:HARD --seeds 20 --seed 1 --jobs 3`，改前 dev
`f07b8965` / 改后）：四人终极胜 1/20 → 1/20（到达首领 8 → 7，漏怪 225.0 → 237.7）；四人绝境 12/20 → 13/20（剩余生命
43.5 → 50.1）；双人绝境 10/20 → 10/20（到达首领 13 → 17，剩余生命 16.9 → 25.9）。R10 盟约阶数之和 6.1 → 6.5（终极）、
6.1 → 6.3（四人绝境）：队伍的盟约更分散。全人机队伍的胜率在 20 局的噪声内不变；这项改动面向和真人组队时的体验。

回放基准：单人场景全部不变；双人／三人／四人的对局场景移动（默认 12 个，第一期下半 7 个、第一期上半 7 个、第二期上半
8 个），全部重新生成。首次后果是开局策略和采购的不同：例如默认 `coop2-NORMAL-1-unowned-roster` 第 0 回合人机抽到的
策略改变（`prepFunds` 0 → 4），`coop4-ABYSS-7` 由胜（第 14 回合）变为负（第 13 回合）、`coop2-HARD-4` 由第 12 回合
全灭变为第 13 回合失败。测试：`test/match/bot-smarter.test.js` 新增两项（低阶避让、自身策略豁免、主盟约、淘汰；
鸭爵有队友时的抽取率 < 单人的四分之一），原「5 阶以下不受影响」的断言改为逐卡检查 1–4 阶扣 12、5–6 阶扣 18。
